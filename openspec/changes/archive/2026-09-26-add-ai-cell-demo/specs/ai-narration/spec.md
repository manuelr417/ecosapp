# Spec Delta

## Purpose

Conversational, kid-friendly narration of detection results, delivered as a stream and backed by a three-rung fallback ladder (primary lab LLM endpoint, secondary lab LLM endpoint, canned responses) so narration never stalls the live demo.

## ADDED Requirements

### Requirement: Narrate detection results in plain language
The system SHALL generate a short narration in plain, audience-friendly language describing what the analysis detected, for both everyday-object and cell-cluster results.

#### Scenario: Narrating a successful detection
- **WHEN** an analysis returns one or more detections
- **THEN** the narration describes the detected objects in simple language suitable for a teenage audience

#### Scenario: Narrating empty results
- **WHEN** an analysis returns zero detections
- **THEN** the narration explains that nothing familiar was recognized, in simple language

### Requirement: Streaming delivery
The narration SHALL be delivered incrementally as it is generated, so the first words appear without waiting for the full text.

#### Scenario: First words arrive early
- **WHEN** a narration begins generating
- **THEN** partial narration text is delivered and displayable before generation completes

### Requirement: Fallback ladder for narration
The system SHALL attempt narration through the primary LLM endpoint first, then the secondary LLM endpoint, and finally canned narration content, automatically moving down the ladder when a rung fails.

#### Scenario: Primary endpoint unreachable
- **WHEN** the primary LLM endpoint does not respond within a short timeout and a narration is requested
- **THEN** the narration is generated by the secondary LLM endpoint

#### Scenario: All models unavailable
- **WHEN** neither the primary nor the secondary LLM endpoint is available
- **THEN** a canned narration is served for designated rehearsal images, and a generic pre-written message is served for other images

### Requirement: Bounded wait per rung
The system SHALL NOT wait indefinitely on any single narration source; each rung of the fallback ladder MUST have a bounded timeout on the order of a few seconds.

#### Scenario: Slow primary endpoint
- **WHEN** the primary LLM endpoint accepts the connection but produces no response within its timeout
- **THEN** the system abandons that rung and continues down the fallback ladder

### Requirement: Narration uses detection data only
The system SHALL send only textual detection results (labels and confidence information) to the narration source, and MUST NOT send the submitted image itself.

#### Scenario: Privacy of submitted images
- **WHEN** a narration is requested for any analyzed image
- **THEN** the request to the narration source contains detection text only and no image bytes
